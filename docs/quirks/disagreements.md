# Where the documents disagree

[Back to the register index](../QUIRKS.md).

Each entry below is a place where two documents, or a document and the C, say different things, with the documents (path and line), the C line and which side matches the C. Nothing is fixed here: no note, record, comment, test or tool was edited. The C lines come from the merge's opening of `linuxdoom-1.10/`; the review's spot-check re-opened a sample.

There are **75 entries**, of which **7** are marked *(policy claim)*: they are about what a frozen policy admits, refuses or declares, or about a decision's status, and are listed for the owner, not edited (COMPATIBILITY is the authoritative home of those). The corner-traversal entry was settled on 2026-11-22. The entries are the work list for the follow-up documentation pull request that corrects them.

Observations that are not disagreements (a document that is merely narrower, a sweep entry that was wrong, a note that only explains) are in the Notes of the page of the C file they belong to.
