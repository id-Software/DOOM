## Notes on the i_video.c rows

- **Q-i_video-102**: M5B fact 26 marks the keysym values as external knowledge and "whether a layout produces them at index 0" as inference.
- **Q-i_video-203**: M5B labels the X behaviour an inference; "No real X server was run" (fake server model).
- **Q-i_video-218**: The Windows stuck-fire report in COMPAT is a separate matter of the app, not this quirk.
- **Q-i_video-799**: Neither is about the C, which matches the quirk as stated.
- **Q-i_video-799-2**: COMPAT names it as one of four reasons the mouse layer "is not playable"; the sweep's verification of that aggregate also found grabMouse set only by `-grabmouse` (i_video.c:83, 738) and the warp only then (321).
- **Q-i_video-218**: COMPAT names no cause; M5B names the bit-8 slip; not contradictory.
