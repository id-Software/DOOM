## Notes on the p_switch.c rows

- **Q-p_switch-652**: F did not open the function's tail; the `return true` is at 652.
- **Q-p_switch-113**: A sweep entry cited p_switch.c:107-148; the episode filter loop runs to 140.
- **Q-p_switch-228**: One sweep entry marks the full-volume consequence as an inference in M5c (1.2.6.3 "(I)"); COMPATIBILITY states it outright and says it was compared on 64 synthetic items and 61 runs.
- **Q-p_switch-652**: The player-side effect in a sweep entry's first entry (the trace stops with no sfx_noway) comes from PTR_UseTraverse, which calls P_UseSpecialLine for any special line and returns false whatever it returned (p_map.c:1113-1122), not from the return value.
