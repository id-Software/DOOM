## Notes on the p_doors.c rows

- **Q-p_doors-142**: the sweep's citation 159-162 is the default branch inside the `crushed` case (151-165).
- **Q-p_doors-413**: The source comment at 364 ("only front sides can be used") sits beside `side = 0` while the sector read uses side^1, the back side.
- **Q-p_doors-416**: COMPAT's wire-23 row names DR lines "1, 26-28"; the C switch also includes 117 (blazing raise), which is not in Episode 1.
- **Q-p_doors-416**: The same switch's "JDC: bad guys never close doors" (p_doors.c:430-431) is design, not part of this quirk.
- **Q-p_doors-416-2**: the D1 line's special is cleared (p_doors.c:482) only on this path, which always creates a thinker.
- **Q-p_doors-118**: from the C, the `open` type is also missing from the down branch's pastdest switch and would behave the same if reversed (the register builder's reading; no document says so).
- **Q-p_doors-416**: M4A §3.14 item 2 says it refines M3h8 §2.4.
